포트폴리오 편집

화면의 문구를 클릭해 수정하세요. 저장하면 로컬 소스에 반영됩니다.

문구 수정

왼쪽 화면에서 수정할 문구를 클릭하세요.

미리보기를 불러오고 있습니다.

사용 방법

  1. 상단에서 페이지를 선택합니다.
  2. 수정할 문구를 클릭하고 내용을 입력합니다.
  3. 미리보기로 확인한 뒤 저장합니다.

저장 전 미리보기는 파일을 바꾸지 않습니다. 같은 프로젝트 안의 동일한 문구는 함께 저장됩니다.

링크를 따라가려면 Alt(⌥)를 누른 채 클릭하세요. 필터는 그대로 사용할 수 있습니다.

링크 주소, 프로젝트 ID, 기술 태그는 이 화면에서 수정하지 않습니다.

공개 사이트에 반영하려면 기존처럼 커밋 후 push하세요.

프로젝트 추가

기본 정보와 첫 사례를 입력하세요. 추가하면 프로젝트 목록과 상세 페이지에 표시됩니다.

프로젝트 정보
관련 직무 (하나 이상 선택)
첫 사례
사례 분야 (해당하는 항목만 선택)
